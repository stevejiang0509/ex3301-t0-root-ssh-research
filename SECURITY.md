# Security and disclosure

This repository documents observations from a single owner-controlled router. It is not an advisory for every EX3301-T0 firmware version. Please do not send live credentials, configuration exports, serial numbers, host keys, or firmware dumps in an issue.

For a suspected additional affected version, privately contact the repository owner through GitHub before posting a working exploit or device-specific evidence. Include model, exact firmware version, the smallest sanitized observation, and whether the device configuration was restored.

The project contains no remote automation. The offline demo does not contact a router.
