# EX3301-T0 in Zyxel's CVE-2026-6952 advisory

Zyxel's [21 July 2026 security advisory](https://www.zyxel.com/global/en/support/security-advisories/zyxel-security-advisory-for-post-authentication-command-injection-vulnerability-in-certain-dsl-ethernet-cpe-fiber-onts-and-wireless-extenders-07-21-2026) describes an administrator-authenticated command injection in the syslog `LogServer` field. Its EX3301-T0 entry lists **`5.50(ABVY.8)C0` and earlier** as affected and **`5.50(ABVY.8.1)C0`** as the patch. The official `V5.50(ABVY.7.2)C0` firmware tested in this repository is within the published affected range.

The [companion CVE-2026-6952 model-scope repository](https://github.com/stevejiang0509/zyxel-cve-2026-6952-model-scope) maintains the complete 42-model advisory table, including affected versions, patches, and evidence status. The other 41 models have **not** been tested by this project. The vendor's advisory confirms the affected input and command-execution effect for its listed products; the specific syslog-ng path, `uid=0` result, and subsequent root SSH account change documented here are findings from one EX3301-T0 running 7.2C0.

Zyxel says its table excludes ISP-customized models and directs ISP customers to their provider for the appropriate firmware. The Hyperoptic `Y1` build in this device's history was not separately tested for CVE-2026-6952. The patch listing does not itself establish that retail `8.1C0` is safe to install on an ISP-customized unit.

The [CVE record](https://raw.githubusercontent.com/CVEProject/cvelistV5/main/cves/2026/6xxx/CVE-2026-6952.json) currently names only AX7501-B1 in its structured `affected` field. The broader 42-model table comes from Zyxel's advisory, not that JSON field. CVE-2025-13943, concerning log-file download, is a distinct issue and is not used to infer this firmware's patch status.
